# Privacy Policy for A-Traductor

Effective date: June 24, 2026

A-Traductor is a browser extension that helps users translate web pages, selected text, and documents. This Privacy Policy explains what data the extension handles and how it is used.

## Single Purpose

A-Traductor's single purpose is to provide translation tools inside the browser. The extension lets users translate web pages, selected text, and supported document content, choose translation services, configure target languages, and manage translation preferences.

## Data We Handle

A-Traductor may process website content only when needed to provide translation features. This can include page text, selected text, document text, page structure, page URL or host name, and response content type information.

The extension does not collect or store the following categories of personal or sensitive user data:

- Personally identifiable information, such as name, email address, mailing address, age, or government ID
- Health information
- Financial or payment information
- Authentication information, such as passwords, credentials, security questions, or PINs
- Personal communications, such as email, text messages, or chat messages
- Precise location data
- Browsing history as a user profile
- User activity for tracking, advertising, analytics, or profiling

## How Website Content Is Used

When the user requests a translation, A-Traductor sends the relevant text content to the translation service selected by the user. Supported services may include Google Translate, Bing Translator, DeepL, Yandex, OpenRouter, AiHubMix, or a custom OpenAI-compatible endpoint configured by the user.

Text may also be sent to a text-to-speech provider when the user uses text-to-speech features.

A-Traductor uses this content only to provide translation or text-to-speech functionality. The extension does not use website content for advertising, profiling, user tracking, or sale to third parties.

## Local Storage

A-Traductor uses browser storage to save user settings, such as:

- Target languages
- Selected translation services
- Extension options and preferences
- Keyboard shortcut settings
- Site translation rules
- Translation cache settings

This information is stored locally in the user's browser unless the browser itself syncs extension data according to the user's browser settings.

## Permissions

A-Traductor requests browser permissions only to provide its translation features:

- `storage`: saves extension preferences and translation settings
- `activeTab`: lets the extension translate the current tab after user interaction
- `contextMenus`: adds translation actions to the browser right-click menu
- `webRequest`: reads response headers such as content type, for example to detect PDF pages
- `webNavigation`: supports translation behavior during page navigation when enabled by the user
- Host permissions: allow the extension to read and modify page content on pages the user wants to translate

## Data Sharing

A-Traductor does not sell user data.

A-Traductor does not transfer user data for advertising, creditworthiness, analytics, or unrelated purposes.

When a user requests translation or text-to-speech, the relevant content is sent to the external service selected or configured by the user solely to perform that requested function. Those third-party services may process data according to their own privacy policies.

## Remote Code

A-Traductor does not use remotely hosted code to change extension behavior. Extension code is included in the extension package.

## Security

A-Traductor is designed to process only the data needed for translation features. User preferences are stored using browser-provided extension storage APIs.
